# almuerzosnewhope

Aplicación web para gestionar almuerzos escolares con dos áreas:

- **Administrador**: define y actualiza las opciones de almuerzo.
- **Estudiante**: registra su solicitud eligiendo solo entre las opciones publicadas.

## Uso

1. Abre `index.html` en tu navegador.
2. En la sección **Administrador**, agrega o elimina opciones de almuerzo.
3. En la sección **Estudiante**, completa:
   - Nombre completo.
   - Grupo.
   - Opción de almuerzo disponible.
   - Fecha y alergias (opcional).
4. Envía la solicitud.

## Funciones

- Opciones de almuerzo administrables.
- Solicitudes de estudiantes guardadas en `localStorage`.
- Listado de solicitudes registradas.
- Eliminación individual de solicitudes y limpieza total.
